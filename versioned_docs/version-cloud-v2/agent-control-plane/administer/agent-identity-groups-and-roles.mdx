# Agent Identity Groups and Roles

Groups and roles decide what agent identities may do. Groups collect agent identities so access is granted to them together. Roles decide what each agent identity is allowed to do, by granting it a set of permissions. Both live in the selected environment's identity provider. For how agent identities work, see [AgentID](../../concepts/agentid.mdx).

## Groups

At the organization level, in the left navigation, under **Agent identities**, click **Groups**. The page lists the groups in the selected environment. To create one, click **Create group**.

## Roles

Under **Agent identities**, click **Roles**. The page lists the roles in the selected environment. To create one, click **Create role**.

## See an agent's groups and roles

An agent's groups and roles are on its **Agent ID** page, in the **Groups** and **Roles** tabs. See [Agent ID](../develop/security/agent-id.mdx).
