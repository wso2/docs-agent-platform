# LLM Service Providers

An LLM service provider gives agents access to models. Adding one starts routing AI traffic through the gateway. LLM service providers belong to the organization, and agents use them through their [LLM configurations](../develop/llm-and-tool-configurations.mdx) or the **LLM Providers** section when you create the agent.

At the organization level, in the left navigation, under **Resources**, click **LLM service providers**. To add one, click **Add service provider**. For the steps, see [Register an LLM Service Provider](../../guides/register-llm-service-provider.mdx).

For how LLM service providers work, see [LLM Service Provider](../../concepts/llm-service-provider.mdx).
