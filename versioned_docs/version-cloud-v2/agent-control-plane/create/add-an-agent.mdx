# Add an Agent

Agents are added to a project. An agent is either a platform-hosted agent, which the platform deploys and manages, or an externally-hosted agent, which runs on infrastructure outside the platform and is registered with it.

## Open the Add a New Agent page

1. Log in to the Agent Manager Console at [console.agent-manager.cloud.wso2.com](https://console.agent-manager.cloud.wso2.com/).
2. Select your project from the breadcrumb at the top of the page.
3. In the left navigation, click **Agents**, and then click **New agent**. Alternatively, click **New agent** on the project's **Overview** page.

The **Add a New Agent** page opens.

## Select how to add the agent

| Option | When to use it | Action |
|---|---|---|
| **Externally-Hosted Agent** | The agent already runs outside the platform. Registering the agent connects it to the platform and enables observability and governance. | **Register an agent** |
| **Platform-Hosted Agent** | The platform deploys and manages the agent, with full lifecycle support that includes built-in CI/CD, scaling, observability, and governance. | **Deploy a new agent** |
| **Start Quickly with a Sample** | You want to evaluate the platform with a preconfigured agent. The sample is configured and deployed as a platform-hosted agent. | Select a sample |

For a platform-hosted agent, select the source of the agent:

- **Source Code**: Provide the agent's source code from a repository. For instructions, see [Create an Agent from Source Code](./create-from-source-code.mdx).
- **Agent Catalog**: Select an agent kind from the agent catalog. For instructions, see [Create an Agent from the Agent Catalog](./create-from-the-agent-catalog.mdx).

To create an agent from a sample, see [Create an Agent from a Sample](./create-from-a-sample.mdx).
