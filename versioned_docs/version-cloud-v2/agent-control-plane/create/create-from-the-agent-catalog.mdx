# Create an Agent from the Agent Catalog

The agent catalog holds **agent kinds**: reusable, versioned templates for built agents. When an agent kind is published, it shows up in the catalog for everyone in the organization, and anyone can create an agent from it.

## Steps

1. On the **Add a New Agent** page, click **Deploy a new agent** under **Platform-Hosted Agent**. See [Add an Agent](./add-an-agent.mdx).
2. Under **Agent Catalog**, click **Browse catalog**.
3. On the **Select an Agent Kind** page, pick the agent kind to create your agent from.

If the catalog is empty, it shows **No agent kinds yet**. To add an agent kind to the catalog, publish one from an existing agent. See [Publish to the Agent Catalog](../publish/publish-to-the-agent-catalog.mdx).
