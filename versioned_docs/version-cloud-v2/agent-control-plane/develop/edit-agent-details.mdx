# Edit Agent Details

After you create an agent, you can change its name, description, and labels. The agent handle cannot be changed.

## Edit the agent details

1. Open the agent from the breadcrumb at the top of the Console. The agent's **Overview** page opens.
2. Click **Edit agent**. The **Edit Agent** page opens.
3. Update the following fields as required:

   | Field | Description |
   |---|---|
   | **Name** | The name of the agent. |
   | **Description** *(optional)* | A short description of what the agent does, up to 2000 characters. Markdown is supported; use **Preview** to check it. |
   | **Labels** *(optional)* | Key/value labels to organize and filter resources. Click **Add label**, enter a **Key** (up to 128 characters) and a **Value** (up to 4096 characters), and then click **Add**. |

4. Click **Update agent**.

To change how the agent is built, such as its repository, build type, agent interface, or health checks, see [Configure the build](./build-an-agent.mdx#configure-the-build).
