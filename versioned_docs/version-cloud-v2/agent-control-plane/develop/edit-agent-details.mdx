# Edit Agent Details

You can change an agent's name, description, and labels after you create it.

## Steps

1. Open the agent from the breadcrumb at the top of the Console. Its **Overview** page opens.
2. Click **Edit agent**.
3. On the **Edit Agent** page, change any of these fields:

   | Field | Description |
   |---|---|
   | **Name** | The agent's name. |
   | **Description** *(optional)* | Up to 2000 characters. Markdown is supported. |
   | **Labels** *(optional)* | Key/value labels to organize and filter resources. |

4. Click **Update agent**.

The agent handle isn't on this page. To change how the agent is built, see [Configure the Build](./configure-the-build.mdx).
