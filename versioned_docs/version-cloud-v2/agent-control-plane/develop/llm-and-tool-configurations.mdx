# LLM and Tool Configurations

An agent's configurations connect it to the models and tools it uses. You manage them on the agent's **Configure Agent** page.

## Open the Configure Agent page

1. Open the agent from the breadcrumb at the top of the Console.
2. In the left navigation, under **Agent lifecycle**, click **Configure**.

The page has two tabs.

## LLM Configurations

An LLM configuration connects the agent to an LLM service provider. Click **Add LLM configuration** to add one.

The service providers you can connect to are the ones added at the organization level. See [LLM Service Providers](../administer/llm-service-providers.mdx). For the steps, see [Configure Agent LLM Configuration](../../guides/configure-agent-llm-configuration.mdx).

## Tool Configurations

A tool configuration adds tools that this agent can use. Click **Add tool configuration** to add one.

Tools come from MCP servers. See [MCP Servers](../create/mcp-servers.mdx).
