# API Keys

API keys let clients call a deployed agent. They're issued for a running agent, in the environment it runs in.

Open the agent, and in the left navigation, under **Security**, click **Credentials**. The **API Keys** page opens.

If the agent isn't deployed in the environment yet, the page shows **Deploy your agent to manage its keys**, with the steps **Build**, **Deploy**, and **Create keys**. Click **Go to Deploy** to deploy it. See [Deploy an Agent](../../deploy/deploy-an-agent.mdx).

For how API keys secure an agent's endpoints, see [Secure Agent Endpoints with API Keys](../../../guides/secure-agent-endpoints-with-api-keys.mdx).
