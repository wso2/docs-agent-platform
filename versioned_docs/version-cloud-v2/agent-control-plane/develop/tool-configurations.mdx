# Tool Configurations

A tool configuration adds tools that an agent can use. Tools come from MCP servers. For information on registering an MCP server, see [MCP Servers](../create/mcp-servers.mdx).

## Add a tool configuration

1. Open the agent from the breadcrumb at the top of the Console.
2. In the left navigation, under **Agent lifecycle**, click **Configure**.
3. On the **Configure Agent** page, click the **Tool Configurations** tab.
4. Click **Add tool configuration**.
