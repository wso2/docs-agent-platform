# Runtime Logs

Runtime logs are the logs that the running agent writes. For the logs of a build, see [Build an Agent](../develop/build-an-agent.mdx#view-the-progress-and-logs-of-a-build).

## Open the Runtime Logs page

1. Open the agent from the breadcrumb at the top of the Console.
2. In the left navigation, under **Observability**, click **Runtime logs**.

The **Runtime Logs** page lists the logs of the agent for the selected time range. To reload the list, click the refresh icon. To change the sort order of the logs, click the sort icon.

If no log matches the selected filters, the page shows **No logs found**. Change the search text or select a longer time range.

## Filter logs by level

In the levels list, select one or more of the following levels: **DEBUG**, **INFO**, **WARN**, and **ERROR**. To show logs of all levels, keep **All Levels**.

## Select the time range

In the time range list, select one of the following: **10 minutes**, **30 minutes**, **1 hour**, **6 hours**, **12 hours**, **1 day**, or **7 days**. To set a start and end time, select **Custom time range**.

The default time range is **1 hour**.

## Search logs

To find logs that contain specific text, enter the text in **Search logs**.
