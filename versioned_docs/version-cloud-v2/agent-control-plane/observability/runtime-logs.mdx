# Runtime Logs

The **Runtime Logs** page shows the logs of the running agent. Open the agent, and in the left navigation, under **Observability**, click **Runtime logs**.

To find logs:

- Filter by level, or keep **All Levels**.
- Choose the time range, for example **1 hour**.
- Enter text in **Search logs**.
- Change the sort order, or refresh the list.

If no log matches, the page shows **No logs found**; try adjusting your search or time range.

For the logs of a build, see [Build an Agent](../develop/build-an-agent.mdx#see-a-builds-progress-and-logs).
