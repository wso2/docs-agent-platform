# System Metrics

System metrics show how much CPU and memory the running agent uses, compared with the resources allocated to it.

## Open the System Metrics page

1. Open the agent from the breadcrumb at the top of the Console.
2. In the left navigation, under **Observability**, click **System metrics**.

## View the metrics

The **System Metrics** page has the following charts:

| Chart | Description | Unit |
|---|---|---|
| **CPU Usage** | The CPU that the agent uses over the selected time range. | Cores |
| **Memory Usage** | The memory that the agent uses over the selected time range. | GiB |

Each chart shows the following series:

| Series | Description |
|---|---|
| **Limits** | The maximum amount of the resource that the agent can use. |
| **Requests** | The amount of the resource that is reserved for the agent. |
| **Usage** | The amount of the resource that the agent uses. |

To reload the charts, click the refresh icon.

## Select the time range

In the time range list, select one of the following: **10 minutes**, **30 minutes**, **1 hour**, **6 hours**, **12 hours**, **1 day**, or **7 days**. To set a start and end time, select **Custom time range**.

The default time range is **1 hour**.
