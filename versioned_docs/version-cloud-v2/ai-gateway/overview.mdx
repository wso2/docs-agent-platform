# AI Gateway

The AI Gateway is the runtime that carries traffic between your agents and the LLM providers and MCP servers they use. Every request to an LLM service provider or MCP proxy passes through a gateway, which authenticates the caller, applies rate limits and guardrails, and forwards the request upstream.

You configure gateways from Agent Control Plane, wherever they run. For how gateways work across environments, see [Gateway](../concepts/gateway.mdx).

## Gateway Options

| Gateway | Description | Traffic Via | Best For |
|---|---|---|---|
| **Managed** | WSO2 runs, scales, and upgrades the gateway. Agent Control Plane provisions it for you. | WSO2 cloud | Getting started quickly |
| **Self-hosted** | You run the gateway on your own infrastructure, such as Docker or Kubernetes, and connect it to Agent Control Plane. Traffic stays in your network. | Your infrastructure | Data residency and compliance requirements |
