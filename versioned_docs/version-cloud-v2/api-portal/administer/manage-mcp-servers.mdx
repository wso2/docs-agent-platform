---
title: "Manage MCP Servers"
description: "Add, edit, and remove the MCP servers exposed in the API Portal & AI Hub."
---

The **MCP Servers** page is where you look after the MCP servers that your API Portal & AI Hub offers. From this one page, you can see which MCP servers the portal has, add new ones, edit them, and remove the ones you no longer need.

You need to be an administrator of the API Portal & AI Hub to use this page.

## Open the MCP Servers Page

1. Sign in to the API Portal & AI Hub as an administrator.
2. Open **Settings**.
3. Under **CONTENT**, select **MCP Servers**.

## See Your MCP Servers

The page lists the MCP servers in the portal, in three columns: **MCP Server**, **Version**, and **Status**.

If you have not added any MCP servers yet, the list is empty, and the page asks you to click **Add MCP Server** to get started.

## Add an MCP Server

1. Click **Add MCP Server**. The **Create MCP Server** wizard opens.
2. Go through the three steps of the wizard: **Details**, **Spec**, and **Assets**.

These are the same steps as when you add an API. To see what each step asks for, see [Manage APIs](https://choreolabs.com/documentation/api-management/cloud/api-portal/administer/content/manage-apis/).

## Remove MCP Servers

You can remove one MCP server, or several at once.

1. In the list, select the MCP servers that you want to remove.
2. Click **Delete selected**.
