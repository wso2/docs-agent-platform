The API Portal & AI Hub is where developers and AI agents find what your organization publishes. In AI & Agent Management, it covers the AI capabilities of the portal: the catalog of MCP servers, and the machine-readable endpoints that AI agents use to discover and call what the portal exposes.

For publishing and consuming APIs in the portal, see [API Portal & AI Hub](https://choreolabs.com/documentation/api-management/cloud/api-portal/overview/) in API Management.

| Task | Description |
| :--- | :--- |
| [Discover MCP servers](./discover/browse-mcp-servers.mdx) | Explore the MCP servers in your organization's registry, review their tools, resources, and prompts, and get their connection details. |
| [Discover AI agents](./discover/ai-agent-discovery.mdx) | See how AI agents use `llms.txt` and the machine-readable endpoints of the portal to discover and call published APIs and MCP servers. |
| [Manage MCP servers](./administer/manage-mcp-servers.mdx) | Add, edit, and remove the MCP servers that the portal exposes. |
| [LLM instructions](./administer/llm-instructions.mdx) | Set the name and description at the top of `llms.txt`, and turn AI discoverability on or off for a view. |
