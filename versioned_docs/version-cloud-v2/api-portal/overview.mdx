The API Portal & AI Hub is where developers and AI agents find what your organization publishes. In AI & Agent Management, it covers the MCP servers in the portal.

For publishing and consuming APIs in the portal, and for how AI agents discover the portal, see [API Portal & AI Hub](https://choreolabs.com/documentation/api-management/cloud/api-portal/overview/) in API Management.

| Task | Description |
| :--- | :--- |
| [Discover MCP servers](./discover/browse-mcp-servers.mdx) | Explore the MCP servers in your organization's registry, review their tools, resources, and prompts, and get their connection details. |
| [Manage MCP servers](./administer/manage-mcp-servers.mdx) | Add, edit, and remove the MCP servers that the portal exposes. |
