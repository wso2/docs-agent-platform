# Project

A Project is the primary container for your agents in Choreo Agent Control Plane. You create agents inside a project, and a project is where a **[Deployment Pipeline](./deployment-pipeline.mdx)** is attached to govern how those agents promote across environments.


The grouping is more than a label. Each project gets its own namespace, network boundary, and security policies, so agents in one project are genuinely isolated from agents in another.


## What a Project Holds

- Every **agent** you create or register belongs to one project.
- MCP servers that you have registered with the project level
- A project is bound to exactly one **[Deployment Pipeline](./deployment-pipeline.mdx)**, which determines which environments agents in this project can promote through, and in what order.

## Relationship to Organization

A Project belongs to exactly one **[Organization](./organization.mdx)**. Resources shared across every project in an organization (**[LLM Service Providers](./llm-service-provider.mdx)**, **[Gateways](./gateway.mdx)**) are registered at the organization level, so any project in that organization can reference them. **[MCP Servers](./mcp-proxy.mdx)** can be registered for the organization, where every project's agents can use them, or for a single project, where only that project's agents can use them. A project's MCP servers also include those published from its components.
