# Choreo Agent Management

A managed Choreo Cloud service for deploying, governing, and observing AI agents.

## Overview

Choreo Agent Management is part of Choreo Cloud. You sign in, open a project, and bring your agents. Choreo runs the platform for you: it builds and hosts your agents, and provisions the AI Gateway and identity service for each environment. There is no infrastructure to install or operate.

Your Choreo Cloud organization is shared across Choreo products, so the members, roles, environments, and deployment pipelines you set up in Choreo Cloud apply to your agents too. See [Organization](../concepts/organization.mdx).

## What You Can Do

- **Deploy agents from source.** Point Choreo at a GitHub repository, and it builds the agent, deploys it, and gives it an endpoint. See [Platform-Hosted and Externally-Hosted Agents](../concepts/internal-and-external-agent.mdx).
- **Bring agents you already run.** Register an agent that runs elsewhere, and observe and govern it alongside the agents Choreo hosts.
- **Promote across environments.** Move the same build from development to production along your project's deployment pipeline, with production deployments under a separate permission. See [Deployment Pipeline](../concepts/deployment-pipeline.mdx).
- **Govern models and tools.** Give agents access to LLM service providers and MCP servers through the [AI Gateway](../ai-gateway/overview.mdx), with platform-issued keys, guardrails, and per-tool access control.
- **Give every agent an identity.** Each agent gets an [AgentID](../concepts/agentid.mdx) credential in every environment it runs in.
- **Observe agent behavior.** Capture traces, logs, and metrics for every request. Python agents that Choreo hosts can be instrumented with no code changes. See [Observability](../concepts/observability.mdx).
- **Evaluate continuously.** Score agent quality with built-in and custom evaluators, such as accuracy, safety, reasoning, and tool use. See [Evaluation](../concepts/evaluation.mdx).
